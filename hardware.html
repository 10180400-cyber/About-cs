Computer Hardware

internal hardware Components

  • Performs calculations and executes instructions
  • RAM: Temporary working memory used during processing
  • SSDs (especially NVMe) offer faster performance
  • Main circuit board connecting all components
  • Essential for gaming, design, and AI workloads

External hardware Components

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam

Hardware Cleaning and Maintenance

  1. Microfiber or lint free cloth
  2. Anti static wrist strap optional
  3. Remove laptop battery if possible
  4. Handle parts gently; avoid sharp objects
  5. Keep food/drink away from equipment
